01 / THE BENCHMARK

Shared histories. Repeated outcomes. Explicit costs.

Three questions.
One complete evaluation.

A useful search decision starts with knowing what the next action will change. SearchHorizonBench follows that information from prediction to decision.

01

Predict success

How likely is each continuation to produce a correct answer?

Action probabilities · Brier error
02

Estimate the gain

How much does another search improve expected answer quality?

Search-value error · Gain R²
03

Choose a continuation

Does the expected gain justify the cost of obtaining more information?

Reward minus cost · Decision utility

03 / EXPLORE THE DECISION

Interactive · Recorded measurements

Put a price
on the next search.

Hold one kind of information fixed and vary the other. See how knowledge of search gains and token costs changes decision utility.

TOKEN VALUATION λ

Value each 1,000 tokens.

Utility equals answer correctness minus λ times thousands of tokens.

At 0.005, each 1,000 tokens costs 0.5 utility percentage points.
