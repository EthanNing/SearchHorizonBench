# Sources and attribution

SearchHorizonBench was prepared by Jingjie Ning, Xueqi Li and Yibo Kong at
Carnegie Mellon University. The package preserves the original question IDs,
quoted public history and source references in exported benchmark records.

Underlying sources include:

- HotpotQA: https://hotpotqa.github.io/
- MuSiQue: https://github.com/stonybrooknlp/musique
- Natural Questions: https://github.com/google-research-datasets/natural-questions
- DeepSearchQA: https://huggingface.co/datasets/google/deepsearchqa
- ClueWeb22: https://lemurproject.org/clueweb22/
- FineWeb: https://huggingface.co/datasets/HuggingFaceFW/fineweb
- DeepResearchGym: https://arxiv.org/abs/2505.19253

Original dataset, corpus, and quoted-document rights and licenses continue to
apply. This artifact does not relicense those materials. Consult each original
source for its access and reuse terms. No blanket license for third-party text
is introduced by this package. No new license has been assigned to the project
code in this packaging step; request permission from the authors where needed.

Local credentials, authorization notes and private filesystem paths are excluded
from this release. Model and search services retain their own usage terms.
